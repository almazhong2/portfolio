This project (March 2026 - April 2026) is a pygame LED rhythm machine adapted from Guitar Hero with customization to Disney's movie, Coco.

Coded this for my sorority's Booth, a longstanding tradition at Carnegie Mellon.

The game features:
- Custom laser-cut guitar and boxed guitar fingerboard with addressable RGB lights running through as strings
- Button and strum logic working with implemented beatmap and hit detection to increment a cumulative score counter (orange lights)
- Increasing difficulty as the game progresses
