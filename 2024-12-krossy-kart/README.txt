Project Title and Description
Krossy Kart is a blend of Crossy Road and Mario Kart Elements, 
combining lane-crossing from Crossy Road and collectibles in Mario Kart.

Players will hop through an infinite randomly generated world with the 
traditional Crossy Road elements: patches of grass, roads with cars 
driving by, and rivers that have logs to hop across. The goal will be to 
navigate as far as possible without getting hit by a car or falling into 
the water. Users can collect coins and power-ups and power-downs which 
will be randomly generated when collected.

Run Instructions
1. Download cmu_graphics; place cmu_graphics inside the src folder
2. Locate link.txt, which includes an external link with additional image 
   and sound files. The entire sounds folder and individual images should 
   be on the same level as all py files underneath the src folder.
3. Run game in main.py. Before playing, make the window full screen. After 
   pressing ‘play,’ press the right then left arrow to align the player 
   properly.

Shortcut Commands
There are not many shortcuts since this game is infinite generation. Use WASD or arrow keys to move the player.
