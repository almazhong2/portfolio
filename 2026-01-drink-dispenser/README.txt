This project (January 2026) is a touchscreen-controlled automatic drink dispenser using a Raspberry Pi and Arduino to dispense four different beverages via servo-controlled hardware.

The Raspberry Pi runs a Python/Tkinter GUI on a 7" LCD touchscreen display
The Arduino controls servo motors dispenser drinks

The touchscreen will then display drink options, and tapping an option will trigger a "pouring" animation
View the physical prototype including exterior, interior, servo hardware, and screen in the prototype folder.
